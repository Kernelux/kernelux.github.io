# SliceKit

A Max for Live instrument for micro-sampling: load several samples, slice them
(transients, beats or regions, like Simpler), and play **all the slices from all
the samples as one kit** on the MIDI keyboard, as if several Simplers sat side by
side. Then shuffle the kit, repeat, reverse, layer and mangle it, in the spirit
of Justice / SebastiAn chopping.

Live stays the sequencer: your MIDI clips play the kit. See
[docs/SPEC.md](docs/SPEC.md) for the full design.

## Status: v0.1, not yet run inside Live

Everything here was written and tested without Max (Max doesn't run in the
environment it was built in):

- The logic (slicing, kit model, shuffle, undo, voice allocation, play modes,
  repeat, modifiers, glue, view) is covered by ~500 automated tests in Node.
- The Max patchers are generated by a script and checked structurally (every
  connection, control, parameter and range).
- The audio voice (`max/voice.genexpr`, gen~) is a port of a JS reference
  simulation that is tested in Node, but the gen~ code itself has never been
  compiled by Max.

So expect the first launch to surface a few Max-specific issues (an object
argument, a gen~ syntax detail). [docs/TESTING.md](docs/TESTING.md) is a
step-by-step checklist. When something fails, copy the Max console lines that
start with `SliceKit:` (and any gen~ compile errors) and they can be fixed quickly.

## Requirements

- Ableton Live 12 with Max for Live (Suite, or Standard + Max for Live).
- Max 9 (the glue runs in the `v8` JavaScript object). On Max 8, open the device
  and change the object `v8 slicekit.js ---src ---skstate ---skview` to
  `js slicekit.js ---src ---skstate ---skview`; the code is plain ES5 and runs in both.

## Install

The device is delivered as Max patchers plus scripts in [`dist/`](dist/):

| file | what |
|---|---|
| `SliceKit.maxpat` | the device patcher |
| `slicekit.voice.maxpat` | one voice, loaded 16 times by `poly~` (contains the gen~ DSP) |
| `slicekit.js` | the controller (all logic, bundled) |
| `slicekit-ui.js` | the waveform / keyboard view (jsui) |

1. Copy the whole `dist/` folder somewhere permanent, e.g.
   `~/Music/Ableton/User Library/Presets/Instruments/Max Instrument/SliceKit/`.
2. In Live, create a MIDI track and drag **Max Instrument** onto it (Browser →
   Max for Live → Max Instrument).
3. Click the device's **Edit** button. Max opens the (almost empty) device.
4. In Max, **File → Open** `SliceKit.maxpat` from your copied folder. Select all
   (Cmd/Ctrl-A) and copy (Cmd/Ctrl-C).
5. Go back to the device window, select all, delete, then paste.
6. Open the patcher inspector (View → Inspector with nothing selected, or
   right-click the background → Inspector) and tick **Open in Presentation**.
7. **File → Save As…** and save it as `SliceKit.amxd` **in the same folder** as the
   other `dist/` files, so Max finds `slicekit.js`, `slicekit-ui.js` and
   `slicekit.voice.maxpat` next to the device.
8. Close the Max window. SliceKit appears on the track. Check the Max console
   (in Max: Window → Max Console) for lines starting with `SliceKit:`.

To share the device with another computer, open it, click **Freeze Device** in
the Max toolbar and save. Freezing embeds all the dependencies in the `.amxd`.

## Quick start

1. Drag 2 or 3 samples (from Live's browser or Finder/Explorer) onto the drop zone,
   or click **Load**.
2. Each sample is sliced on transients and its slices are laid out on the keyboard
   from the root key (C1 = 36), sample after sample, each with its own color.
3. Play. Click a key in the strip to select its pad and edit it (PAD section);
   the waveform shows that sample and the selected slice.
4. Try **Shuffle**, the **A–H** map slots, **Chaos**, **Repeat**.

Per sample (SAMPLE section): Mono / Poly / Thru, Trig / Gate, slicing mode,
sensitivity, beat division, BPM, Reslice, Remove. Thru plays from the slice to the
end of its own sample, whatever the keyboard layout.

### Mouse in the view

| where | action |
|---|---|
| sample tabs | click: select the sample |
| waveform | click: select slice · Shift-click: add a slice point · Alt-click a marker: remove it · drag a marker: move it |
| key strip | click: select key · Shift-click: audition · Cmd/Ctrl-click: lock / unlock · ‹ › : scroll by octave |

### Modifier zone (Mods on, default start key C6 = 96)

| key | 96 | 97 | 98 | 99 | 100 | 101 | 102 | 103 | 104 | 105 | 106 | 107 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| hold for | rpt 1/4 | 1/8 | 1/8T | 1/16 | 1/16T | 1/32 | 1/64 | reverse | oct − | oct + | tape stop | chaos |

Modifier keys are ordinary MIDI notes, so you can draw them into clips.

## Limits

16 samples, 128 keys, 16 voices, one stereo output (a Max for Live limit, so
per-pad cutoff and drive are built in). Samples are referenced by file path:
use **File → Collect All and Save** in Live before moving a project.

## Development

Requires Node 22.

```
cd slicekit
npm install
npm run check     # build dist/, ES5 lint, patcher validation, all tests
```

| path | what |
|---|---|
| `core/` | pure ES5 logic (slicing, features, model, engine, voice simulation), unit tested |
| `max/glue.js` | Max-side controller (bundled with core into `dist/slicekit.js`) |
| `max/ui.js` | jsui view |
| `max/voice.genexpr` | gen~ voice DSP |
| `tools/` | bundler, patcher generator, validators |
| `docs/` | [SPEC](docs/SPEC.md), [ARCHITECTURE](docs/ARCHITECTURE.md), [PROTOCOL](docs/PROTOCOL.md), [VOICE](docs/VOICE.md), [TESTING](docs/TESTING.md) |

Don't edit `dist/` by hand: change the sources and run `npm run build`.
